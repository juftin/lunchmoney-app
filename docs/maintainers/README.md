parent directory and is not included in the published documentation site.

- [Database guide](DATABASE.md): persistence API and schema work.
- [Checklist](CHECKLIST.md): active implementation work.
- [Roadmap](ROADMAP.md): API coverage and planned work.
- [Technical handoff](AGENT_HANDOFF.md): architecture and sprint details.
- [Incremental ETL](INCREMENTAL_ETL.md): synchronization design.
- [Upstream compatibility](UPSTREAM_COMPATIBILITY.md): Lunch Money API upgrade policy.
- [Dashboard design](DESIGN_DASHBOARD_SPA.md): dashboard implementation design.
